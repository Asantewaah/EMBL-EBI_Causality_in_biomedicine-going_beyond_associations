# AnchorGene Training Data

Synthetic genotype data for the EMBL-EBI training session.

## Quick start
The data is in [`data/geno.csv`](data/geno.csv) — a matrix of
simulated genotypes (samples × SNPs, 0/1/2-coded allele counts),
generated with CEU-calibrated linkage disequilibrium structure.

## Provenance
This is **fully synthetic data**, generated by `simulate_genotypes_CEU.R`
(included in `src/`).
No real individuals or genotype data are involved.
